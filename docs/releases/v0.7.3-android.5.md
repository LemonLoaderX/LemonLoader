Requires **LemonLoader Patcher 1.1.0 or later**, Android API 24+, ARM64, and an
IL2CPP Unity game. Upgrade Patcher before downloading this release.

## Runtime selection

- `LemonLoader-runtime-android-arm64.zip`: default .NET 11 Android CoreCLR with
  Android JNI cryptography.
- `LemonLoader-runtime-bionic-arm64.zip`: .NET 11 Linux Bionic CoreCLR with private
  OpenSSL. Synchronous HTTP/HTTPS worked in prior application testing.
- `LemonLoader-Android-arm64.zip`: identical alias of the Android default.

Both variants use dotnet/runtime commit
`12e2dc84c3fec81acb741410c787f23d8c65e32d`. The .NET 10 runtime is now a frozen
legacy fallback. Android's upstream synchronous HttpClient rejection is
unchanged; use asynchronous requests on that variant.

## Changes

- Shared runtime source baseline with independently selectable runtime packs.
- .NET 11-compatible MonoMod.Common dependency.
- Simplified scripts, explicit isolated development builds, deterministic
  runtime packaging, and fewer redundant hash calculations.
- Release `files[]` protects the crypto DEX; Patcher generates its final APK
  digest. Payload asset layout remains v8.
- CI consumes the versioned runtime packs and builds both distributions.

## Limitations

This remains a preview, not broad game compatibility certification. Android Mono
games and 32-bit ABIs are unsupported; physical 16 KiB-page devices still need
qualification. Existing automated and application evidence does not replace
manual acceptance testing for each game.

Patch an original APK. Switching runtime requires a same-signer replacement APK
and process restart; it is not a hot-swap. No game assets, generated game Interop
assemblies, Mods, signing keys, or private diagnostic evidence are included.
