# Security policy

Please report vulnerabilities through GitHub's private vulnerability reporting
for `LemonLoaderX/LemonLoader`. Do not open a public issue for a vulnerability
that could enable arbitrary file writes, path traversal, signature confusion,
or unsafe native code loading.

Security reports should include the affected revision, Android version and ABI,
the smallest reproducible input, and the observed result. Remove game data,
account information, device identifiers, signing material, and credentials
before attaching evidence.

Only the current Android release line receives security fixes. Historical
development snapshots and unpublished runtime backends are not supported.
